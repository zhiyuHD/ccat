ccat

A single binary that replaces a dozen Unix tools — file viewer, system analyzer, debugger, charting engine, QR generator, and more. All in your terminal.

✦ 40+ features ⟐ ~15K LoC 🦀 Rust 📦 AUR / crates.io 🐧 Linux

📦Install

One binary, zero dependencies at runtime.

⟫ Arch Linux (AUR)

yay -S ccat-rs

Also available via paru, yay, or any AUR helper.

⟫ From source

git clone https://github.com/zhiyuHD/ccat.git cd ccat cargo build --release cp target/release/ccat ~/.local/bin/

Requires Rust 1.80+. Build time: ~2 minutes on modern hardware.

⟫ Shell completions

ccat --completions bash > ~/.local/share/bash-completion/completions/ccat ccat --completions zsh > /usr/local/share/zsh/site-functions/_ccat ccat --completions fish > ~/.config/fish/completions/ccat.fish

📂File Viewer

Auto-detect and render any file format. The core of ccat — what the name implies, pushed way further than plain cat.

— (stdin)

Piped input

Read from stdin with auto-detection. Pipe anything through ccat for syntax-highlighted output.

stdin
--ascii / -A

Plain text mode

Force plain text output, skipping all markdown/docx/image processing.

fallback
--binary / -B

Raw bytes

Display raw binary output without any processing or interpretation.

--type / -T

File type detection

Show detected file type (like file). Uses magic bytes, extensions, and content heuristics.

--diff / -D

Diff viewer

Compare two files with syntax-highlighted diff output. Supports --side-by-side for parallel view.

--hex / -x

Hex dump

Classic hex dump with offset, hex bytes, and ASCII sidebar. Use --hex-canonical for pipe-friendly output.

--inspect / -i

File inspector

Detailed file analysis: type, size, entropy, hashes (MD5/SHA1/SHA256), permissions, and timestamps.

--follow / -f

Tail follow

Watch file for changes (like tail -f). Configure starting line with --lines N.

🔬System Diagnostics

A complete Linux system inspection suite. No more juggling ps, ss, free, top, iostat, lsof — it's all in ccat.

--health

System Health

Unified health assessment with scoring (0–100). Combines memory, CPU, pressure, disk, network, swap, ZRAM, and uptime into a single report.

★ flagshipscorePSI
--meminfo

Memory Analysis

Full /proc/meminfo breakdown: Anon/Cached/Buffers/Slab/PageTables, swap, ZRAM, Huge Pages, commit limit, OOM risk, and page fault counters.

bar chartOOM%
--ps

Process List

Color-coded process list (like ps aux). Sort by PID, MEM, CPU, name, state. Filter by PID, show process tree hierarchy.

--ps-sort--ps-pid--ps-tree
--cpu

CPU Topology

Full CPU analysis: cache hierarchy (L1–L3 by core), frequency scaling, grouped CPU flags (AVX, SSE, crypto, virtualization), IRQ distribution.

topology treeflags
--disk

Disk & Filesystems

Mount table, disk usage per filesystem, and I/O statistics. ZRAM device stats included.

mountsI/O
--netstat

Network Connections

Network connections from /proc/net (like ss -tulpn). Filter by TCP/UDP, listening only, or PID. Color-coded by state with process resolution.

--netstat-tcp--netstat-udp--netstat-pid
--swap

Swap & ZRAM

Comprehensive swap analysis: usage, compression ratio, I/O rates, top swap consumers, PSI pressure correlation. Algorithm recommendations.

compressiontop consumers
--cgroup

Cgroup v2

Full cgroup v2 hierarchy: active controllers, PSI memory/IO/CPU pressure, memory and CPU usage per cgroup.

controllersPSI
--oom

OOM Score Analyzer

Per-process oom_score, oom_score_adj, oom_adj, and RSS. Sorted by risk (red ≥800, orange ≥500). Detects cgroup OOM kills. Top-victim analysis.

risk tiers170 procs
--fd <PID>

File Descriptors

Per-process fd listing from /proc/<pid>/fd. Classifies by type: regular, socket, pipe, eventpoll. Resolves socket addresses. Detects potential leaks.

--fd-alltype icons
--vmmap <PID>

Virtual Memory Map

Process memory map from /proc/<pid>/maps. Per-region permissions, offset, device, inode. Add --vmmap-detailed for RSS/PSS/Swap from smaps.

smapspermissions
--interrupts

IRQ & SoftIRQ

Per-CPU interrupt distribution from /proc/interrupts and /proc/softirqs. Balance indicators (even/mixed/skewed/pinned), sparkline bars.

balance4 CPUs
--sched

Scheduler Analyzer

Linux scheduler deep-dive: policy distribution (OTHER/FIFO/RR/BATCH/IDLE/DEADLINE), involuntary preemption leaders, scheduler tunables, CFS bandwidth.

policiespreemption

🔄Format & Structured Data

Parse, validate, format, and visualize structured data — JSON, YAML, TOML, CSV, and more.

--json

JSON formatting

Auto-detected JSON with syntax highlighting. Color-coded keys, strings, numbers, booleans, and null values.

--yaml

YAML formatting

Syntax-highlighted YAML output with color-coded keys, strings, and data types.

--toml

TOML formatting

Auto-detected TOML with syntax highlighting for tables, keys, and values.

--csv

CSV formatting

Auto-detected CSV with aligned columns and syntax highlighting. Supports TSV variant.

--schema

Schema inference

Infer and display the schema of structured data (JSON, TOML, YAML, CSV) — field names, types, nullability, and sample values.

--chart

ASCII charts

Render tabular data as ASCII bar or line charts. Auto-detects chart type from data shape. Configure X/Y axes with --chart-x and --chart-y.

--chart-typeauto-detect

🛠️Developer Tools

Code review, debugging, reverse engineering, and source analysis tools.

--elf

ELF binary introspection

Parse ELF binaries: headers, sections, segments, program headers, dynamic symbols. Architecture detection (x86/x86_64/ARM/AArch64/RISC-V).

reverse engineering
--disasm

Disassembly (third call)

Three consecutive runs on a binary trigger interactive x86/x86_64 disassembly via iced-x86. Shows instructions with addresses and bytes.

x86/x64
--source

Source code

Syntax-highlighted source code rendering. Choose from 200+ themes via --theme (syntect). List available themes with --list-themes.

--diff / -D

Unified diff

Auto-detects unified diff from stdin. Syntax-highlighted additions and deletions. Side-by-side mode with --side-by-side.

--search / -g

Grep mode

Regex search in files with color-highlighted matches. Context lines (-C N), match counts (-c), file-only mode (-l).

--todo

TODO scanner

Scan codebases for TODO/FIXME/BUG/HACK/OPTIMIZE/TEMP/NOTE/REVIEW annotations. Color-coded by severity. Git blame integration with --todo-blame.

--todo-kind--todo-stats
--git

Git object viewer

Display git objects: blobs, trees, commits, and tags. Pass a SHA/ref to inspect an object, or a path to show git log history.

--log

Log highlighting

Auto-detected log files with level-based coloring (ERROR=red, WARN=yellow, INFO=green, DEBUG=cyan). Timestamp detection.

🎨Visual & Creative

Images, QR codes, audio metadata, and HTML output — ccat isn't just for text.

-- (image file)

Image rendering

Auto-detects Kitty terminal protocol, Sixel, and falls back to half-block character rendering. Supports PNG, JPEG, GIF, WebP, BMP, TIFF.

--media

Audio/Video metadata

Extract and display audio/video metadata: codec, bitrate, sample rate, duration, tags. Supports MP3, FLAC, OGG, WAV, AAC, MP4, MKV, WebM.

--qr / -Q

QR code generation

Generate QR codes from text or piped input. Four ECC levels (L/M/Q/H). Color inversion with --qr-invert. Pure Rust (qrcode crate).

--qr-ecc--qr-invert
--html

HTML output

Generate HTML output from any input file for browser viewing. Combined with --serve PORT to start an HTTP server.

--serve <PORT>

HTTP server

Start a lightweight HTTP server to serve files as rendered HTML. Great for sharing formatted documents over the network.

--chart

ASCII charting

Render numerical data as terminal charts. Auto-detect bar or line chart. Works with piped data or files.

🧰Utility

Everyday terminal productivity features.

-n / --number

Line numbering

Number all output lines. Use -b to number only non-blank lines.

-s / --squeeze-blank

Squeeze blanks

Squeeze consecutive blank lines into a single blank line.

-e / --edit

Sed substitution

Apply sed-like substitution expressions (e.g. s/foo/bar/) to the output.

--tree / -r

Directory tree

Display directories as a tree with file types, sizes, and line counts. Dotfiles with --all, depth limit with --depth N.

--archive

Archive browser

List and preview files inside archives: ZIP, TAR, GZip, BZip2, XZ, Zstd, Brotli, DEB, RPM. Preview individual files with --archive archive.deb Makefile.

--archive-format
--watch / -w

Auto-refresh

Watch mode: re-run system diagnostics every N seconds (like watch). Supports all system modes. --watch-once for a clean one-shot refresh.

Ctrl-C exit
